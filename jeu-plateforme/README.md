# Champi Run

Mini jeu de plateforme 2D original (HTML5 Canvas, aucune dépendance). Suivi du projet dans Pilotage : `jeu-plateforme`.

Commandes : ← → bouger · Espace/↑ sauter · R recommencer (boutons tactiles sur mobile).

Lancer : ouvrir `index.html`. Déploiement : site statique Vercel (Root Directory = `jeu-plateforme`).
